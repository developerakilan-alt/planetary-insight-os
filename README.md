# Cosmos OS

You are an award-winning UX designer, senior frontend architect, 3D graphics engineer, and AI product designer.

Build a world-class production-ready web application called

"COSMOS OS"

Tagline:

The Future of Planetary Exploration.

This should NOT look like a portfolio website.

This should NOT look like a landing page.

This should look like software used inside NASA, ISRO, ESA, JPL, or a modern planetary research laboratory.

The application must feel like a premium enterprise operating system for exploring planets using AI, scientific visualization, and real mission datasets.
